A RISC-V core, written from scratch

A complete RV32I processor in Verilog with its own control logic and datapath, verified by running assembly programs directly on the core and checking every writeback in the waveforms.

Built

  • Instruction fetch, decode, ALU, register file and writeback
  • Control flow for branches, jumps and program termination

Debugged

  • Register writeback integrity across instruction classes
  • Control-flow hazards, traced through waveform timing

Tools

  • Verilog HDL
  • Icarus Verilog
  • GTKWave
  • RISC-V assembly
